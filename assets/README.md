# Fonts go here

The fonts aren't included in this repository for licensing reasons. Add these files to this folder before building:

- `Pillar.ttf`: the clock digits
- `SF-Pro-Display-Regular.otf`
- `SF-Pro-Display-Medium.otf`
- `SF-Pro-Display-Bold.otf`
- `SF-Pro-Display-Light.otf`

See the [Fonts section of the main README](../README.md#fonts) for where to get them, or how to use different fonts.
